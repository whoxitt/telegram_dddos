# 🔐 Telegram Auth Manager Bot

Бот для управления авторизациями в Telegram аккаунтах.

## Возможности

✅ Вход в аккаунты с новым кодом каждый раз
✅ Сохранение аккаунтов с подписями  
✅ Управление несколькими аккаунтами
✅ Повторная отправка кода
✅ Поддержка 2FA

## Деплой на Render

### Шаг 1: Fork репозиторий

Нажми "Fork" на GitHub

### Шаг 2: Деплой на Render

1. Зайди на [render.com](https://render.com)
2. Войди через GitHub
3. Нажми "New" → "Web Service"
4. Выбери этот репозиторий
5. Настройки будут автоматически из `render.yaml`
6. Добавь переменную окружения:
   - Key: `BOT_TOKEN`
   - Value: твой токен от @BotFather

### Шаг 3: Запуск

Нажми "Create Web Service" - готово! 🎉

## Локальный запуск

1. Установи зависимости:
```bash
pip install -r requirements.txt
```

2. Создай файл `bot_token.txt` с токеном бота

3. Запусти:
```bash
python bot.py
```

## Технические детали

- Python 3.11+
- python-telegram-bot 20.7
- telethon 1.45.0
- БЕЗ прокси (работает на сервере напрямую)

## Переменные окружения

- `BOT_TOKEN` - токен бота от @BotFather (обязательно)

## Файлы

- `bot.py` - основной файл бота
- `requirements.txt` - зависимости Python
- `render.yaml` - конфигурация для Render
- `accounts.json` - сохраненные аккаунты (создается автоматически)
- `session_*.session` - сессии Telegram (создаются автоматически)

## Команды бота

- `/start` - главное меню
- Все остальное через кнопки!

## Использование

1. Нажми `/start`
2. "➕ Добавить аккаунт"
3. Введи номер телефона
4. Введи код из Telegram
5. Добавь подпись (опционально)
6. Готово! ✅
